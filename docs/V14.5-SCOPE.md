# DadoFit V14.5 — Ad Campaign Management

## Objetivo
Convertir `SuperAdmin > Publicidad > Control de pauta` en gestión real de campañas existentes.

## Incluye
- Editar campaña existente.
- Precarga de marca, campaña, imagen, destino, fechas y placement.
- Guardar cambios sin recrear la campaña ni perder `ad_events`.
- Edición en vivo para campañas activas.
- Duplicar una campaña como base de un nuevo borrador.
- Mantiene Activar / Pausar.
- Auditoría `ad_campaign.update` con before/after.
- Campañas `completed` y `cancelled` quedan de solo lectura; se pueden duplicar.

## Decisión de producto
No se agrega eliminación libre. Borrar una campaña que ya tiene impresiones/clics destruiría historial comercial y trazabilidad. Para retirar una pauta se usa Pausar/Cancelar; para reutilizarla se usa Duplicar.
