# DadoFit V15.8.1 — Global Visual System

## Objetivo
Unificar visualmente las pantallas protegidas de DadoFit usando el lenguaje aprobado en `/app`: graphite oscuro, acento lime, superficies compactas y jerarquía fitness premium.

## Alcance visual
- Header y navegación con la misma geometría entre rutas.
- Ancho máximo de contenido de 1180 px.
- Alineación vertical uniforme entre `/app`, `/rewards` y páginas secundarias.
- Heroes, cards, tabs, filtros, formularios, modales, estados vacíos y tablas armonizados.
- Rewards conserva el layout ECO-3 y las correcciones de imágenes de V15.8.
- Backoffice Admin conserva su sidebar, pero adopta la misma paleta y superficies.
- Responsive tablet/mobile normalizado.

## Rutas cubiertas
`/app`, `/profile`, `/notifications`, `/gymbros`, `/challenges`, `/squads`, `/sponsored-challenges`, `/seasons`, `/rewards`, `/rewards/manage`, `/rewards/analytics`, `/rewards/validate`, `/organizations`, `/organization-challenges`, `/gym-battles`, `/workspace`, `/brand-campaigns`, `/brand-competitions`, `/brand-audit`, `/admin/*`.

## Fuera de alcance
No modifica contratos de datos, lógica de negocio, Supabase, migraciones, RLS, RPC, economía, permisos, publicidad ni reglas de canje.

## QA recomendado
1. Comparar `/app` y `/rewards`: header, margen superior y ancho deben sentirse iguales.
2. Recorrer Perfil, Retos, Squads, Gym, Marca y Admin.
3. Probar dark desktop y mobile.
4. Confirmar que Rewards conserva canjes GP/SP/DC y saldos multi-moneda.
5. Ejecutar `npm test` y `npm run build` antes de commit.
