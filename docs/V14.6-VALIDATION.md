# Validación V14.6

## Instalación
Extraer el ZIP sobre la raíz de `reto-byads` y reemplazar archivos.

No ejecutar `supabase db push`: V14.6 no tiene migraciones.

```bash
npm test
npm run build
npm run dev
```

## Test 1 — Desktop amplio
Viewport >=1600px.

Esperado:
- continúan los rails izquierda/derecha;
- no aparece dock inferior;
- formatos 160x600 / 300x600 siguen intactos.

## Test 2 — Ventana reducida
Reducir la ventana a ~900–1200px.

Esperado:
- desaparecen los rails laterales;
- aparece un dock inferior con 2 unidades compactas;
- una campaña activa en `workout-left-top` sigue visible;
- el contenido no queda tapado porque existe spacer inferior;
- el dock se puede cerrar.

## Test 3 — Varias posiciones vendidas
Activar campañas en top y middle.

Esperado:
- el dock rota únicamente entre grupos con campañas activas;
- cambio de grupo cada 15 segundos;
- la rotación interna de campañas de cada placement continúa según el tiempo configurado en Admin.

## Test 4 — Mobile
Viewport <=767px.

Esperado:
- una sola unidad inferior;
- si `workout-mobile` tiene campaña activa, se usa esa;
- si está vacío, se reutiliza la primera campaña desktop activa;
- no hay dos banners sticky simultáneos.

## Test 5 — Analytics
Con usuario autenticado:
1. dejar la pauta visible >1 segundo;
2. hacer clic;
3. abrir `/admin/ads`;
4. actualizar analytics.

Esperado:
- impresión registrada;
- clic registrado;
- route/device correctos;
- placement conserva la clave comercial original.
