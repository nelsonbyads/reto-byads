# DadoFit V14.3 — Validación

## 1. Migración
Ejecutar:

```bash
npx supabase migration list
npx supabase db push
```

Debe aplicarse:

`20260902154500_ad_rotation_billboard.sql`

## 2. Build

```bash
npm test
npm run build
npm run dev
```

## 3. Configuración SuperAdmin
1. Entrar a `/admin/ads`.
2. En `Lateral izquierdo · superior`, elegir por ejemplo `8s` o `12s`.
3. Mantener la campaña Nike activa.
4. Crear una segunda campaña usando exactamente el mismo placement `workout-left-top`.
5. Activar la segunda campaña.

Resultado esperado: la activación NO debe mostrar el antiguo error de placement ocupado.

## 4. Inventario
La tarjeta del placement debe mostrar:
- `2 campañas en rotación`.
- Los nombres de las campañas.
- `Cambia cada 8s/12s/...`.

## 5. Vista usuario
Abrir `/app`, `/challenges` o `/gymbros` en desktop >=1600 px.

Resultado esperado:
- La primera creatividad aparece con el mismo diseño de V14.2.1.
- Aparece un indicador discreto `1/2` arriba a la izquierda.
- Transcurrido el tiempo configurado cambia a `2/2` y a la segunda creatividad.
- Después vuelve a `1/2`.
- El tamaño del placement y el ancho central NO cambian durante la rotación.
- No hay fondo oscuro no solicitado.
- No hay recorte destructivo de la creatividad.

## 6. Pausa
Desde `/admin/ads`, pausar una de las dos campañas.

Resultado esperado:
- El placement queda con una sola campaña.
- Deja de rotar.
- El indicador `1/2` desaparece.

## 7. Auditoría
Entrar a `/admin/audit`.

Deben registrarse eventos como:
- `ad_placement.rotation.change`
- `ad_campaign.status.change`
