# Validación V14.5

1. Extraer el ZIP en la raíz del proyecto.
2. Ejecutar:

```bash
npx supabase migration list
npx supabase db push
node scripts/check-supabase.mjs
npm test
npm run build
npm run dev
```

El healthcheck debe mostrar:

```text
Schema: v14.5-ad-campaign-management
```

## Prueba funcional

1. Ingresar como SuperAdmin a `/admin/ads`.
2. En una campaña existente presionar `Editar`.
3. Confirmar que el formulario se llena automáticamente.
4. Cambiar, por ejemplo, `Campaña`, `Destino URL` o `Placement`.
5. Presionar `Guardar cambios`.
6. Confirmar que la misma campaña aparece actualizada y conserva su estado.
7. Si estaba activa, abrir una página con publicidad y confirmar el cambio en vivo.
8. Revisar `/admin/audit`: debe existir `ad_campaign.update`.
9. Presionar `Duplicar`: debe precargar una nueva campaña con `(copia)` y al guardar debe crearse como borrador independiente.
10. Confirmar que analytics históricos de la campaña original siguen presentes.
