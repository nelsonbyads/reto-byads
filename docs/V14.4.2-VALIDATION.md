# DadoFit V14.4.2 — Health/schema version synchronization

## Causa corregida

`scripts/check-supabase.mjs` consulta `dadofit_health()`, no `get_dadofit_schema_version()`.
La función `dadofit_health()` conservaba el valor hardcodeado `v14-platform-superadmin-backoffice` desde V14.

## Solución

`dadofit_health()` ahora usa:

```sql
public.get_dadofit_schema_version()
```

como fuente canónica del número/nombre de versión.

## Validación

```bash
npx supabase migration list
npx supabase db push
node scripts/check-supabase.mjs
```

Resultado esperado:

```text
DadoFit -> Supabase: OK
Schema: v14.4-ad-analytics-click-tracking
```

Luego continuar con la prueba funcional de Ad Analytics.
