# V15.8 — Fitness Premium UI + Rewards Fix v2

## Objetivo
Adoptar la direccion visual de referencia fitness premium (dark graphite + lime/neon) sin romper la funcionalidad actual.

## Rewards
- La imagen queda aislada en una caja con `aspect-ratio` y `overflow: hidden`.
- `object-fit: cover` evita desbordes.
- Titulo y descripcion se limitan para preservar altura.
- El bloque de pagos queda en el footer de la card.
- GP/SP/DC conservan sus reglas ECO-3.
- El hero deja de mostrar solo DC y presenta wallets separados por organizacion.
- GP no se suman entre Gyms; SP no se suman entre Marcas.
- Los estados `Límite alcanzado` y `Agotado` usan un unico bloque de estado.

## App visual
- Dark pasa a ser la apariencia de referencia de V15.8.
- Header, navegación y superficies principales reciben el lenguaje graphite/lime.
- Se mantienen Claro y Pastel como opciones del selector.

## Sin cambios de backend
No contiene migraciones SQL ni cambios de contrato Supabase.
