# DadoFit V15.3 — Gym Challenge Economy & Monetization

## Objetivo

Cerrar tres brechas detectadas durante QA real con Titanes:

1. Evitar que un reto aprobado sin payout parezca haber entregado DC/XP/GP.
2. Permitir que el Gym configure la recompensa del reto antes de publicarlo.
3. Mantener inventario publicitario visible dentro del workspace Gym, sin monetizar el workspace Marca.

También se incluye el hotfix V15.2.2 de notificaciones de premios de Gym y un backfill idempotente para ofertas activas que no notificaron a sus miembros.

## Reglas de recompensa

Los retos del Gym pueden configurar por participante aprobado:

- DadoCoins: 0–25 DC
- Experiencia: 0–50 XP
- Gym Points: 0–100 GP

`GP` es el nombre de producto para el campo histórico `sponsor_points`. No se hace una migración destructiva del esquema.

`TP` (Team Points) NO aplica a un reto institucional del Gym. TP pertenece a Squads y batallas de Squad.

## Anti-farming preservado

- Mismo Gym -> mismo miembro: máximo 1 reto con recompensa económica/competitiva por ventana móvil de 24 horas.
- Mismo usuario: máximo 5 recompensas de organizaciones en 24 horas.
- El reto puede quedar aprobado aunque el payout sea bloqueado.
- Cuando el payout se bloquea, el participante recibe 0 DC / 0 XP / 0 GP.

## Claridad de UI

Antes de aprobación:

`Recompensa potencial` + valores configurados.

Después de aprobación:

`Recompensa otorgada` + valores realmente entregados.

Si anti-farming bloquea el payout:

`Reto aprobado · sin recompensa` y se explica el motivo.

## Monetización Gym

Se monetizan estos contextos cuando el workspace activo es `gym`:

- `/workspace`
- `/organizations`
- `/organization-challenges`
- `/gym-battles`
- `/rewards/manage`
- `/rewards/validate`

El workspace `brand` permanece sin pauta operativa en esas rutas.

## Notificaciones de premios

Cuando un Gym activa una oferta, sus miembros activos reciben una notificación una sola vez por oferta.

V15.3 además hace backfill idempotente de ofertas Gym que ya estaban activas antes del hotfix, para cubrir casos como el premio de Titanes creado durante QA.
