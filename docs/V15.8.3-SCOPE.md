# DadoFit V15.8.3 — Workout Theme Homologation

## Objetivo
Homologar `/app` con el lenguaje visual global V15.8 ya usado en Retos,
Premios y las demás rutas protegidas.

## Causa
`/app` todavía consumía una segunda familia de tokens CSS (`--df-*`) definida
por estilos históricos de Workout. V15.8.1 normalizaba `--bg`, `--panel`,
`--primary`, etc., pero varios componentes de Entrenar seguían leyendo
`--df-surface`, `--df-border`, `--df-mint`, entre otros.

## Solución
Se añade un bridge de tokens y overrides finales dentro de
`v15.8.1-global-visual-system.css`, cargado al final de la cascada existente.

Incluye:
- superficies graphite unificadas;
- bordes neutrales iguales a Retos;
- lime como acento global;
- dado y tile de ejercicio sin gris frío legacy;
- botón Lanzar Dados con primary global;
- KPI bar homogénea;
- selección de nivel alineada al sistema global;
- eliminación del acento mint exclusivo de Workout.

## Fuera de alcance
- Supabase/RPC/RLS;
- ECO-2/ECO-3;
- reglas de canje;
- lógica del dado;
- filtros y dataset de ejercicios;
- publicidad.
