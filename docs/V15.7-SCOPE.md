# V15.7 — Pre-Release Feature Pack

## Objetivo

Cerrar en un único paquete los pendientes funcionales del roadmap antes de entrar en Feature Freeze y QA final.

## Incluye

### 1. Unified Challenges

El Gymbro mantiene rutas especializadas, pero deja de depender de conocer su separación técnica.

Centro contextual:

```text
1 vs 1
Del Gym
Squads
Patrocinados
Temporadas
```

Rutas conservadas:

```text
/challenges
/organization-challenges
/squads
/sponsored-challenges
/seasons
```

No se reescriben los engines de retos existentes.

### 2. TP / GP Seasons

Se reutiliza la foundation histórica ya existente:

```text
seasons
score_events
challenges.season_id
```

Semántica:

```text
TP = Team Points = Squads
GP = Gym Points  = Gyms
```

`score_events` sigue siendo el ledger. Cerrar una temporada nunca elimina puntos anteriores.

V15.7 crea una temporada Squad y Gym del mes actual solo si no existe una activa. Nuevos retos se asocian automáticamente a su temporada global. También se hace backfill de retos/eventos del rango actual que todavía tengan `season_id = null`.

### 3. Sponsored Gym Competitions

Una Brand verificada Owner/Admin puede:

```text
crear competencia
seleccionar >= 2 Gyms verificados
configurar inicio / fin
enviar invitaciones
consultar aceptación
consultar ranking GP
```

Gym Owner/Admin puede:

```text
aceptar
rechazar
```

La competencia patrocinada calcula GP por su ventana temporal. No cambia `season_id` de los eventos y por tanto puede coexistir con la temporada global Gym.

### 4. TP / GP semantics

La UI de Gym deja de presentar `SP` / `Sponsor Points` y muestra `GP` / `Gym Points`.

Internamente puede conservarse:

```text
sponsor_points
```

por compatibilidad con el schema y migraciones anteriores.

## Seguridad

- creación de temporada global: SuperAdmin;
- creación de competencia patrocinada: Owner/Admin de Brand verificada;
- respuesta a invitación: Owner/Admin del Gym invitado;
- rankings: autenticados;
- score writes continúan server-owned;
- no se habilitan writes directos del browser sobre `score_events`.

## Fuera de alcance

No incluye:

```text
cash-out
crypto
P2P DadoCoins
billing complejo
premios monetarios automáticos de temporada
torneos bracket multi-ronda
```

Esos temas requieren producto/reglas adicionales y no bloquean el feature freeze actual.
