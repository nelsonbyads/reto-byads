# Validación V15.0

## Instalación
1. Extraer ZIP sobre la raíz del proyecto.
2. `npx supabase migration list`
3. `npx supabase db push`
4. `node scripts/check-supabase.mjs`
5. `npm test`
6. `npm run build`
7. `npm run dev`

Health esperado:
`Schema: v15.0-rewards-marketplace-foundation`

## Prueba A — Crear premio como Partner
1. Entrar con Owner/Admin de Nike o Titanes.
2. Cambiar al workspace correspondiente.
3. Abrir `Ofertas`.
4. Crear un premio en borrador, por ejemplo:
   - Bono $50.000
   - 100 DC para prueba
   - stock 5
   - máximo 1 por usuario
5. Publicar.

Esperado: organización verificada publica; Member/Coach no puede administrar.

## Prueba B — Canje personal
1. Entrar como Gymbro con saldo suficiente.
2. Ir a `Premios`.
3. Canjear la oferta.

Esperado:
- saldo baja exactamente el costo;
- se crea un `wallet_transaction` negativo;
- aparece código `DF-...`;
- stock restante baja 1;
- historial conserva proveedor, título y costo.

## Prueba C — Anti abuso
Intentar canjear nuevamente una oferta con máximo 1 por usuario.

Esperado: backend bloquea el segundo canje y NO descuenta DadoCoins.

## Prueba D — Saldo insuficiente
Usar una oferta más costosa que el saldo.

Esperado: botón deshabilitado y backend también rechaza si se invoca el RPC manualmente.

## Prueba E — Stock
Poner stock 1, canjear con un usuario y abrir con otro.

Esperado: `Agotado`; no puede sobre-venderse.
