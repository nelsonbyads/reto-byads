# DadoFit V15.8.5 — Challenge Surface Parity

## Problema corregido
La capa V15.8.4 estaba cargada al final, pero varias reglas críticas usaban `:where(...)`.
` :where()` aporta especificidad 0. Los CSS legacy de V10/V11/V12/V13 tenían reglas dark mode
con mayor especificidad y, en algunos casos, colores hard-coded como `#191f29`, `#151b24`,
`#202733` y `#272626`. Por eso la interfaz mezclaba superficies azul-gris con el negro-verde
nuevo aunque la cobertura estructural estuviera presente.

## Solución
- Overrides de alta especificidad para Challenge Center.
- Mismo panel principal de Rewards: `#0d100e`.
- Panel secundario: `#111511`.
- Bordes lime discretos: `rgba(221,255,92,.14)`.
- Estados semánticos conservan significado sin usar slabs verdes claros.
- Cobertura explícita de 1 vs 1, Del Gym, Squads, Patrocinados y Temporadas.
- Test actualizado para exigir selectores de paridad con alta especificidad.

## No modifica
- Supabase / SQL / RLS / RPC.
- ECO-2 / ECO-3.
- GP / SP / DC.
- Reglas de retos o recompensas.
- Rutas.
