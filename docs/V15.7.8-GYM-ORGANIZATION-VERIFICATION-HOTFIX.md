# V15.7.8 - Gym / Organization Verification Hotfix

## Problema
Admin > Organizaciones mostraba el estado `pending_verification` de los Gyms, pero no renderizaba acciones. Las acciones solo existían en Admin > Marcas y el RPC de escritura rechazaba tipos `gym`.

## Cambios
- Admin > Organizaciones ahora siempre muestra la columna **Acciones**.
- Para Gym pendiente aparece **Aprobar**.
- Se puede devolver a **Pendiente**, **Rechazar** o **Suspender**.
- Nuevo RPC `admin_set_organization_verification` válido para Gym y demás organizaciones.
- El RPC antiguo `admin_set_brand_verification` queda como wrapper compatible.
- Los cambios quedan registrados en `admin_audit_log`.

## QA
1. Crear un Gym y confirmar `pending_verification`.
2. SuperAdmin > Organizaciones.
3. Pulsar **Aprobar**.
4. Confirmar estado `verified`.
5. Confirmar que el Gym puede ser elegido en flujos que exigen Gyms verificados.
