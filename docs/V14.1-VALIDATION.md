# DadoFit V14.1 — Footer institucional + Centro Legal

## Alcance

Este paquete es incremental sobre V14 y no contiene migraciones.

Incluye:
- Footer global profesional en páginas de producto, contacto y legales.
- Centro legal con páginas reales: Términos, Privacidad, Cookies, Tratamiento de Datos y Normas de Comunidad.
- Enlaces comerciales a Contáctanos con tipo de solicitud precargado.
- Consentimiento de privacidad/tratamiento de datos en el formulario de contacto.
- Disclaimer visible de DadoCoins como puntos de fidelización no monetarios.

## Validación técnica

```bash
npm test
npm run build
npm run dev
```

No ejecutar `supabase db push`: V14.1 no incluye migraciones.

## Validación funcional

1. Entrar a `/app` y hacer scroll hasta el final.
   - Debe aparecer el footer oscuro.
   - El banner sticky mobile no debe reemplazar el footer.
2. Probar enlaces:
   - `/contact`
   - `/terms`
   - `/privacy`
   - `/data-policy`
   - `/cookies`
   - `/community-guidelines`
3. Desde el footer seleccionar `Publicidad y alianzas`.
   - `/contact?type=advertising`
   - El select debe abrir precargado en `Quiero pautar`.
4. Probar `Registrar una Marca` y `Registrar un Gym`.
   - El tipo de solicitud correspondiente debe precargarse.
5. En Contáctanos intentar enviar sin aceptar la política.
   - El navegador debe exigir el checkbox.
6. Confirmar que el footer NO se muestre en:
   - `/login`
   - `/register`
   - `/business-setup`
   - `/admin/*`
7. Revisar responsive en 390 px, 768 px, 1440 px y 1920 px.

## Nota legal

Los textos incluidos establecen un marco funcional coherente con la arquitectura actual de DadoFit. Antes de una publicación comercial definitiva, la organización responsable debe validar jurídicamente los textos e incorporar, cuando corresponda, su razón social, identificación tributaria, domicilio y canales formales de privacidad.
