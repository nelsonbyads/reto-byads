# DadoFit V13.1 - Exercise Catalog Picker

## Brand flow
1. Open Brand workspace -> Brand Campaigns.
2. In "Publicar reto", click the Exercise search field.
3. Search `push`, `squat`, `burpee`, etc.
4. Pick an exercise from the DadoFit catalog.
5. The selected exercise card must show its canonical name and metadata.
6. Set Meta, Duration and capacity.
7. Publish after Brand/campaign verification rules are satisfied.

## Custom activity fallback
1. Click "Crear actividad personalizada".
2. Type an activity not present in the catalog.
3. Publish normally. It receives an internal custom exercise id.

## Gymbro flow
1. Open Personal workspace -> Sponsored Challenges.
2. Catalog-based challenges should show the official DadoFit exercise media.
3. "Cómo hacerlo" should show catalog instruction steps when available.
4. Custom activities should continue to work without catalog media.

## Technical validation
- `npx supabase db push`
- `node scripts/check-supabase.mjs` -> `v13.1-sponsored-exercise-catalog`
