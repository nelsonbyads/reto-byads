# DadoFit V13.5.1 — Multi-slot Desktop Ads

## Objetivo
Aprovechar la altura disponible del entrenamiento en desktop con tres ubicaciones publicitarias independientes por lateral.

## Inventario desktop
- Izquierda superior
- Izquierda media
- Izquierda inferior
- Derecha superior
- Derecha media
- Derecha inferior

Total: 6 placements desktop potencialmente vendibles.

## Responsive
- >=1600 px: 160x600 por placement.
- >=1900 px: hasta 300x600 por placement.
- <1600 px: rails desktop ocultos como antes.
- Mobile: conserva el banner sticky inferior de V13.5 sin cambios.

## Validación rápida
1. `npm test`
2. `npm run build`
3. `npm run dev`
4. Abrir `/app` en una pantalla >=1600 px.
5. Confirmar un anuncio superior en cada lado.
6. Hacer scroll: debe aparecer un segundo placement por lado.
7. Continuar el scroll: debe aparecer un tercer placement por lado.
8. Confirmar que el ancho y posición del entrenamiento central no cambian.
9. En mobile confirmar que sigue existiendo un único banner sticky inferior.

## Sin cambios
No modifica Supabase, Auth, Rewards, evidencias, dados, ejercicios, workspaces, auditoría ni reglas de negocio.
