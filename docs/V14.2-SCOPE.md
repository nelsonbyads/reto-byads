# V14.2 — Monetización transversal

Este release convierte los 6 placements desktop administrados desde SuperAdmin en inventario transversal del ecosistema Personal de DadoFit.

No crea tablas ni migraciones. Reutiliza `ad_placements`, `ad_campaigns`, `ad_campaign_placements` y `get_active_ad()` de V14.

Principio: las vistas de consumo/social pueden monetizarse; los entornos operativos de Gym, Brand, SuperAdmin, autenticación y legales permanecen limpios.
