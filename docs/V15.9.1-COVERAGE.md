## Footer
El footer se normaliza por separado porque `SiteFooter` se renderiza fuera de los shells de las rutas. Se elimina el sistema navy + azul/naranja legacy y se lleva a graphite + lime.

## Guard automático
`src/lib/uiHomologation.test.ts` valida:
- que todas las rutas protegidas de `App.tsx` estén inventariadas;
- que cada ruta tenga cobertura profunda, no solo el shell;
- que Gymbros, Rewards secundarios, Admin y Footer tengan selectores explícitos;
- que la capa final no use `:where()` para evitar perder por especificidad;
- que no vuelvan colores legacy azul-gris ni el footer tricolor;
- que ECO-3 cargue antes del sistema visual final.
