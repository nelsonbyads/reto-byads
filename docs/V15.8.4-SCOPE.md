# DadoFit V15.8.4 — Challenge Center Homologation + UI Coverage Guard

## Objetivo
Eliminar la dependencia de revisión visual manual para detectar módulos que quedaron fuera del sistema V15.8.

## Corrección visual
Se agrega un puente único de tokens legacy hacia los tokens V15.8 para todo el producto protegido. Esto cubre módulos antiguos que todavía consumen `--df-*`, `--surface`, `--border` o `--muted`.

Se homologa explícitamente el Challenge Center completo:
- 1 vs 1 (`/challenges`)
- Del Gym (`/organization-challenges`)
- Squads (`/squads`)
- Patrocinados (`/sponsored-challenges`)
- Temporadas (`/seasons`)

Incluye navegación, heroes, cards, tabs, formularios, estados, modales, rankings y acciones.

## Guardia automática
`src/lib/uiHomologation.test.ts` se ejecuta automáticamente con `npm test`.

La prueba falla si:
1. aparece una ruta protegida nueva en `App.tsx` sin contrato visual;
2. una ruta protegida conocida deja de estar cubierta por el stylesheet global;
3. se pierde el puente de tokens legacy;
4. el stylesheet global deja de cargarse después de ECO-3;
5. vuelve a importarse la capa `dadofit-modernist-*` descartada.

Esto es una guardia estructural de cobertura. No es un comparador pixel-perfect. Para regresión visual pixel a pixel sería necesario añadir Playwright/Chromium como una segunda capa de QA.

## Sin cambios funcionales
No modifica Supabase, migraciones, RPC, RLS, GP/SP/DC, reglas de retos, recompensas ni permisos.
