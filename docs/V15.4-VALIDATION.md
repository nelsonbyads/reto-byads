# DadoFit V15.4 — Validation

## Migración

Aplicar:

```bash
npx supabase db push
```

Verificar:

```sql
select public.get_dadofit_schema_version();
```

Esperado:

```text
v15.4-rewards-analytics
```

## Partner

1. Entrar con Owner/Admin de Titanes.
2. Cambiar al workspace Gym.
3. Abrir `Ofertas` → `Analytics`.
4. Probar 7 / 30 / 90 días.
5. Confirmar que los KPIs corresponden a canjes reales.
6. Confirmar que una oferta con stock restante bajo aparece en alertas.
7. Confirmar que Coach/Member no puede obtener analytics mediante RPC.

## SuperAdmin

1. Entrar a `/admin/rewards`.
2. Revisar DC emitidos, DC consumidos y DC en circulación.
3. Comparar el ranking de partners con canjes existentes.
4. Abrir con usuario no SuperAdmin y confirmar bloqueo.
