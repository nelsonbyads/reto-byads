# DadoFit V15.3 — Validation

## Instalación

1. Extraer el ZIP sobre la raíz del proyecto.
2. Reemplazar archivos existentes.
3. Aplicar migraciones.

```bash
npx supabase migration list
npx supabase db push
node scripts/check-supabase.mjs
npm test
npm run build
npm run dev
```

Schema esperado:

```text
v15.3-gym-challenge-economy-monetization
```

## Prueba A — claridad anti-farming

Con Bro2 abre `/organization-challenges`.

Un reto aprobado y premiado debe mostrar:

```text
Recompensa otorgada
25 DC · 50 XP · 100 GP
```

Un segundo reto Titanes aprobado dentro de 24 h debe mostrar:

```text
Recompensa otorgada
0 DC · 0 XP · 0 GP
Reto aprobado · sin recompensa
Titanes ya te otorgó una recompensa durante las últimas 24 horas.
```

La tarjeta ya no debe insinuar que los 25 DC fueron entregados.

## Prueba B — recompensa configurable

En workspace Titanes -> Entrenar -> generar tirada -> Reto de mi Gym.

Configura por ejemplo:

```text
DC: 10
XP: 20
GP: 40
```

Publica.

Bro2 debe ver esos valores como `Recompensa potencial`.
Si es elegible y el Owner aprueba la evidencia, debe recibir exactamente 10 DC / 20 XP / 40 GP.
