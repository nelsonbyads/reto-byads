# DadoFit V13.5 — Responsive Monetization UX

## Scope

V13.5 only changes advertising presentation. It does not change Supabase, auth,
workout rules, evidence, rewards, organizations, audit or RBAC.

## Desktop

1. Open `/app` at a viewport >= 1600 CSS px.
2. Confirm left and right vertical ad rails are visible.
3. Confirm the workout center remains stable and readable.
4. At >= 1900 CSS px, confirm both rails expand to 300px while the center stays 1180px.
5. Confirm no horizontal overflow.

## Mobile

1. Open `/app` at <= 767px.
2. Confirm one sticky banner appears at the bottom.
3. Scroll to the last workout action and confirm the banner does not cover it.
4. Close the banner with the X button and confirm it disappears for the current render.
5. Confirm `/profile`, `/brand-audit`, `/workspace` and forms do not receive this sticky banner.

## Themes

Check Pastel, Claro and Oscuro. The ad inventory must use theme tokens and keep
sufficient contrast in all three.

## Technical gate

```bash
npm test
npm run build
npm run dev
```

Only after Vite approval rebuild Docker.
