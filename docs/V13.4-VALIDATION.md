# DadoFit V13.4 — Final UX/UI Polish

## Alcance

V13.4 es una capa visual final sobre V13.3.1. No modifica Supabase, migraciones, Auth, RLS, RPCs, recompensas, evidencia, anti-farming ni auditorías.

Pantallas cubiertas:

- `/gymbros`
- `/challenges`
- `/squads`
- `/organizations`
- `/organization-challenges`
- `/gym-battles`
- `/sponsored-challenges`
- `/notifications`

## Objetivos

- Mismo ritmo visual del nuevo `/profile` y Workspace Marca.
- Cards, botones, tabs, formularios, badges y estados vacíos consistentes.
- Mejor responsive desktop/tablet/mobile.
- Mantener los tres temas Pastel / Claro / Oscuro.
- Cero cambios a reglas de negocio.

## Instalación

Extraer el ZIP en la raíz del repositorio y aceptar reemplazo de `src/main.tsx`.

V13.4 no agrega migraciones SQL.

```bash
npm test
npm run build
npm run dev
```

## Smoke test visual

Validar navegación y carga, sin necesidad de repetir todos los flujos de negocio:

1. `/gymbros`
2. `/challenges`
3. `/squads`
4. `/organizations`
5. `/organization-challenges`
6. `/gym-battles`
7. `/sponsored-challenges`
8. `/notifications`

En cada pantalla verificar:

- Header V13.3.1 conservado.
- Fondo y paneles respetan el tema.
- No hay overflow horizontal.
- Botones y cards mantienen jerarquía.
- Modales siguen abriendo.
- Acciones existentes siguen visibles.

## Criterio de aprobación

Si `npm test` + `npm run build` pasan y las ocho pantallas cargan sin regresiones funcionales, V13.4 puede entrar al checkpoint RC2.
