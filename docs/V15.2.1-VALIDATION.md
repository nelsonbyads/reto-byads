## Instalación
Extraer el ZIP sobre la raíz de `reto-byads` y aceptar reemplazo.

```bash
npm test
npm run build
npm run dev
```

## Caso 1 — Filtros
1. Abrir `/app`.
2. Presionar `Filtros`.
3. Confirmar que el overlay cubre también el header.
4. Confirmar que `Mi perfil`, notificaciones, apariencia y usuario no aparecen encima del drawer.
5. Confirmar scroll interno del panel.
6. Cerrar con X, clic sobre el backdrop y tecla Escape.

## Caso 2 — Cómo hacerlo
1. Lanzar dados.
2. Abrir `Cómo hacerlo`.
3. Confirmar que todos los pasos se leen con contraste suficiente en Claro/Pastel.
4. Cambiar a Oscuro y confirmar que el texto sigue usando el color del tema y permanece legible.

## Resultado esperado
- Cero solape entre header y drawer.
- Fondo de la página no scrollea mientras el drawer está abierto.
- Texto de instrucciones legible y sin apariencia deshabilitada.
