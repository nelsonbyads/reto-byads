# Crear el primer SuperAdmin DadoFit

El SuperAdmin es un permiso global de plataforma y NO un tipo de workspace.

1. Desde `/register`, crear una cuenta cloud eligiendo **Perfil personal**.
2. Si la confirmación de correo está habilitada, confirmar el correo.
3. Verificar que la cuenta exista en Supabase Auth.
4. En Supabase SQL Editor, ejecutar `docs/V14-SUPERADMIN-BOOTSTRAP.sql` del paquete V14 y reemplazar `TU_CORREO_SUPERADMIN@DOMINIO.COM` por ese correo.
5. Cerrar sesión y volver a iniciar sesión.
6. En el menú del usuario aparecerá **Administración DadoFit**.
7. También se puede abrir directamente `/admin`.

No crear el SuperAdmin como Gym ni como Marca para otorgarle permisos globales. Esos workspaces son independientes del rol de plataforma.
