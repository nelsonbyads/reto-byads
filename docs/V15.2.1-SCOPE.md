# DadoFit V15.2.1 — Filter Overlay + Instruction Legibility Hotfix

## Objetivo
Corregir dos regresiones visuales confirmadas en `/app` sin alterar V15.2 Rewards/QR ni la monetización responsive.

## Cambios
- El drawer de Filtros pasa a una capa global superior al header y sus popovers.
- El overlay bloquea interacción con el header mientras Filtros está abierto.
- El `body` queda sin scroll durante el modal y se restaura al cerrar.
- `Escape` cierra el drawer.
- En mobile se conserva el comportamiento de bottom-sheet.
- Se aumenta el contraste del texto de `Cómo hacerlo`, respetando la variable de texto del tema activo.

- filtros o selección de ejercicios;
- dados;
- evidencias;
- retos;
- rewards V15;
- publicidad;
- Supabase/RLS/migraciones.
