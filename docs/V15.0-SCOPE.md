# DadoFit V15.0 — Rewards Marketplace Foundation

## Objetivo
Cerrar el ciclo económico inicial de DadoFit: ganar DadoCoins → descubrir premios → canjear → conservar historial.

## Incluye
- Catálogo personal `/rewards`.
- Saldo de DadoCoins y filtros de catálogo.
- Canje atómico desde backend con validación de saldo, stock, vigencia y límite por usuario.
- Historial personal de canjes y código único.
- Gestión de ofertas `/rewards/manage` para Owner/Admin de Gym o Brand.
- Crear, editar, publicar, pausar y finalizar ofertas.
- Marcas/Gyms no verificados pueden preparar borradores, pero no publicar.
- Auditoría de cambios de ofertas en `reward_offer_events`.
- Snapshots del premio al momento del canje para conservar histórico aunque la oferta cambie.
- Navegación `Premios` para Personal y `Ofertas` para Gym/Brand.

## No incluye todavía
- QR físico / escáner de recepción (V15.2).
- Confirmación de entrega por Gym/Marca (V15.2).
- Dashboard global de rewards para SuperAdmin (V15.3).
- Reembolsos administrativos (V15.3).
- Marketplace P2P o cash-out. DadoCoins siguen siendo puntos cerrados de fidelización.

## Seguridad
Las escrituras sensibles se realizan mediante RPC `SECURITY DEFINER`; el frontend no descuenta DadoCoins directamente. El canje bloquea la oferta y el wallet dentro de la misma transacción PostgreSQL.
