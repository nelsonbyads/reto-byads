# V15.7.4 — Admin Season Actions Visibility Hotfix

## Fix
- `Editar` in SuperAdmin > Temporadas now has an explicit class and explicit foreground/background colors.
- All season action buttons now use explicit text/icon colors instead of inheriting global Admin button colors.
- `Cerrar temporada` keeps the same explicit readable treatment.

## Migration
None.

## Quick QA
1. Open `/admin/seasons`.
2. An `UPCOMING` season must show `Editar` visibly.
3. An `ACTIVE` season must show both `Editar` and `Cerrar temporada` visibly.
4. Click `Editar`; the form must load the selected season.
