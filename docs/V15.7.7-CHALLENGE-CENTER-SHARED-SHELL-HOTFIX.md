# V15.7.7 - Challenge Center Shared Shell Hotfix

## Root cause
The Challenge Center navigation was rendered inside each route-specific `main` container.
Those containers do not share the same layout context: for example, Sponsored Challenges
uses a flex column with `gap`, while Seasons has its own width/padding rules.

Previous fixes locked the nav height and adjusted padding, but the nav was still being
laid out inside different parent geometries. This allowed subtle route-to-route movement.

## Fix
- Move `ChallengeCenterNav` outside each route-specific `main`.
- Render it in a common `challenge-center-shell-v1577` directly below `AppHeader`.
- Remove viewport-centering transforms from the nav inside that shell.
- Keep route-specific content layouts unchanged.
- No database migration.
