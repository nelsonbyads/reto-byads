# DadoFit V13.2.1 - Sponsored review history hotfix

## Fix
`review_sponsored_challenge()` no longer uses `ON CONFLICT (participant_id)`.
`challenge_reviews` intentionally stores multiple rows per participant so rejection/resubmission cycles remain auditable.

## Validate
1. `npx supabase migration list`
2. `npx supabase db push`
3. `node scripts/check-supabase.mjs`
4. Retry **Aprobar** on the participant that is already `submitted`.
5. Confirm +25 DC / +50 XP once.
6. Confirm participant becomes `approved`.
7. Confirm second approval does not grant again.

No frontend replacement is required.
