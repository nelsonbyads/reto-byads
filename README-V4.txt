DADOFIT UI/UX V4 - BYADS BRAND SYSTEM

REEMPLAZO ULTRA SIMPLE:

1. Deten npm run dev.
2. Copia este archivo sobre el existente:
   src/styles/byads-v3.css
3. No reemplaces ningun otro archivo.
4. Ejecuta:
   npm test
   npm run build
   npm run dev
5. Revisa http://localhost:5175/app
6. Si apruebas la visual:
   docker compose up -d --build

Esta V4 mantiene el nombre byads-v3.css a proposito para que NO tengas que editar main.tsx.
