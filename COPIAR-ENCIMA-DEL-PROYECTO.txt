DadoFit V15.8 — Fitness Premium UI + Rewards Fix v2

BASE REQUERIDA
==============
Aplicar sobre el proyecto que ya tiene ECO-2 + ECO-3 restaurados.

QUE CAMBIA
==========
- Nuevo lenguaje visual fitness premium oscuro + lime/neon.
- Apariencia oscura pasa a ser la referencia inicial de V15.8.
- Rewards: imagen con caja fija y object-cover; no vuelve a tapar texto.
- Rewards: cards estables en altura y contenido.
- Rewards: footer de pago GP/SP/DC anclado al final.
- Rewards: el hero muestra saldos reales DC + GP por Gym + SP por Marca.
- Rewards: "Limite alcanzado" / "Agotado" se muestra una sola vez, no un boton duplicado por moneda.
- Responsive: 3 columnas desktop, 2 tablet, 1 mobile.
- Ajuste visual compatible para otras superficies de la app sin tocar reglas de negocio.

NO CAMBIA
=========
- Supabase
- Migraciones
- RPCs
- Reglas ECO-2 / ECO-3
- Auth
- Permisos
- Logica de canje

INSTALACION
===========
1. Detener npm run dev.
2. Descomprimir este ZIP.
3. Copiar TODO el contenido de la carpeta sobre la raiz de reto-byads.
4. Aceptar combinar carpetas y reemplazar archivos.
5. Ejecutar:

   npm test
   npm run build
   npm run dev

NO ejecutar npx supabase db push para este paquete.
